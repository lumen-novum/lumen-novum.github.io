These assets are the artist's recreation of Mac OS X Jaguar (10.2) traffic lights, not extracted Panther (10.3) system assets.

## Web exports

`close.png`, `minimize.png`, and `maximize.png` were exported from the PSD's `Close`, `Minimize`, and `Maximize` layer groups, respectively, using `psd-tools`. Each group was composited separately with its original artwork, vector masks, and blend modes. The existing `Icon` layer was hidden during export to select the regular state without ×, −, or + symbols. The source PSD was not modified, and no artwork was redrawn or recolored.

Changes from the source format: the selected groups were converted to transparent, 32 × 32 RGBA PNG files for web use. The portfolio displays them at 16 × 16 CSS pixels. The source PSD is retained in the repository worktree but excluded from the published site.
